2. 0/1 Knapsack using Dynamic Programming

Time Complexity:
There are two nested loops.
The first loop runs n times for the items.
The second loop runs W times for the knapsack capacity.

Therefore:
Time Complexity = O(n × W)

Space Complexity:
A DP table of size (n + 1) × (W + 1) is used.

Therefore:
Space Complexity = O(n × W)


3. Longest Common Subsequence (LCS)

Time Complexity:
There are two nested loops.
The first loop runs n times for the first string.
The second loop runs m times for the second string.

Therefore:
Time Complexity = O(n × m)

Space Complexity:
A DP table of size (n + 1) × (m + 1) is used.

Therefore:
Space Complexity = O(n × m)
